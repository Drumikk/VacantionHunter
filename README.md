# VacationHunter

Минималистичный агрегатор вакансий с объяснимым разбором запроса, нормализацией зарплат, дедупликацией, проверкой подлинности и ранжированием по полному логическому «И», затем по взвешенному «ИЛИ».

Географический scope: РФ/СНГ, Европа, Америки, Австралия/Новая Зеландия и глобальные remote/ATS-площадки. Отдельные локальные источники Азии, Ближнего Востока и Африки не подключаются.

## Уже реализовано

- разбор русских и английских запросов на роль, навыки, зарплату, валюту/период, локацию, remote, relocation, опыт и занятость;
- приоритеты тегов и уточняющие вопросы;
- нормализация часовой, месячной и годовой зарплаты в USD/месяц;
- ранжирование: полные обязательные совпадения → взвешенная релевантность → зарплата → свежесть → надёжность;
- дедупликация по ID источника, canonical URL, fingerprint и fuzzy title/company/location;
- проверка вакансии по происхождению, компании, сроку, HTTP/JobPosting и риск-фразам;
- коннекторы HH, Remotive, Arbeitnow, tokenized multi-site API Jooble, USAJOBS и настраиваемые публичные ATS-фиды Greenhouse, Ashby, Lever;
- локальный набор данных, поэтому интерфейс работает без сети;
- сохраняемые наблюдения за поиском: отдельное JSON-хранилище, фоновые обновления и SSE-уведомления для опции «следить за новыми»;
- Telegram-доставка новых совпадений: серверная очередь на диске, дедупликация событий, exponential backoff, учёт `retry_after`, тест канала и автоматический поиск `chat_id`;
- сортировка по двум полям и объяснение скоринга в каждой карточке.

## Запуск

Требуется Node.js 20+; внешние npm-зависимости не нужны.

```powershell
npm test
npm start
```

Открыть `http://127.0.0.1:4173`.

Для быстрого офлайн-запуска:

```powershell
$env:ENABLE_LIVE_SOURCES='false'
npm start
```

Для постоянной локальной настройки скопируйте `.env.example` в `.env` и заполните нужные ключи. `.env` загружается сервером автоматически, исключён из git и не должен передаваться другим людям.

## Конфигурация источников

```text
PORT=4173
ENABLE_LIVE_SOURCES=true
REFRESH_INTERVAL_MS=900000
REQUEST_TIMEOUT_MS=8000
MAX_JOBS_PER_SOURCE=100
HH_USER_AGENT=VacationHunter/0.1 (contact: ваш_реальный_email)
HTTP_USER_AGENT=VacationHunter/0.1
JOOBLE_API_KEY=полученный_ключ
USAJOBS_API_KEY=полученный_ключ
USAJOBS_EMAIL=реальный_email_регистрации
TELEGRAM_BOT_TOKEN=токен_из_BotFather
TELEGRAM_CHAT_ID=id_личного_чата_или_канала
AGGREGATOR_CACHE_MS=900000
GREENHOUSE_BOARDS=company-one,company-two
ASHBY_BOARDS=CompanyOne,CompanyTwo
LEVER_SITES=company-one,company-two
```

Наблюдаемые поиски сохраняются локально в `data/watch-store.json` и после перезапуска снова попадают в фоновое обновление. Это однопользовательский режим MVP; для многопользовательского развёртывания потребуются аккаунты и серверная база данных.

ATS-параметры — это публичные board/site slug конкретных компаний. Обход авторизации не реализуется: для закрытых данных нужен OAuth, API-ключ или партнёрский фид.

Те же ATS-источники можно описать объектами в `config/sources.json`: `slug`, отображаемое `name`, карьерный `homepage`, `regions` и `enabled`. Каждая company board становится отдельным коннектором и получает собственные health, error count и cooldown; сбой одной компании не маскируется общим статусом ATS.

`HH_USER_AGENT` намеренно не имеет фиктивного значения по умолчанию: HH требует валидный User-Agent и может блокировать тестовые домены. Укажите название приложения и реальный контактный email; без этого коннектор отображается как `disabled`. Ответы 401/403, Cloudflare challenge и 429 переводят источник в cooldown, чтобы фоновое обновление не создавало лишнюю нагрузку. CAPTCHA, Cloudflare и геоблокировки не обходятся — используется официальный API/RSS, партнёрский доступ либо источник отключается.

Для максимально широкого автоматического поиска сначала получите `JOOBLE_API_KEY` на <https://jooble.org/api/about>. Jooble агрегирует вакансии с множества job boards и карьерных страниц, поэтому этот коннектор расширяет покрытие без поддержки отдельного HTML-парсера для каждого сайта. `USAJOBS_API_KEY` и `USAJOBS_EMAIL` подключают официальный поиск федеральных вакансий США. Подробная архитектура, ограничения LinkedIn/Indeed и регистрация: [автоматический сбор](docs/INGESTION.md).

Кнопка состояния источников в верхней панели открывает центр диагностики: готовность каждого коннектора, требуемые имена переменных `.env`, официальный URL регистрации, последняя успешная синхронизация, cooldown и точечная кнопка «Проверить сейчас». Значения ключей API сервер в этот интерфейс не передаёт.

## Telegram-уведомления

1. Создайте бота через [официальный @BotFather](https://t.me/BotFather) командой `/newbot` и сохраните токен в `TELEGRAM_BOT_TOKEN`.
2. Напишите новому боту `/start` или добавьте его в нужный канал.
3. Перезапустите VacationHunter, откройте центр источников и нажмите «Найти chat ID».
4. Скопируйте найденный ID в `TELEGRAM_CHAT_ID`, снова перезапустите приложение и нажмите «Отправить тест».
5. Сохраните нужный поиск переключателем «Следить за новыми». При появлении новых совпадений планировщик поставит компактный дайджест в durable-очередь и отправит его в Telegram.

`data/notification-outbox.json` исключён из git. Событие имеет устойчивый dedupe key, успешная доставка хранит `message_id`, временная ошибка повторяется с экспоненциальной задержкой, а Telegram `retry_after` имеет приоритет. После `NOTIFICATION_MAX_ATTEMPTS` сообщение остаётся в состоянии `failed`; кнопка «Повторить очередь» вручную возвращает такие записи в доставку. Токен не возвращается через API и не попадает в браузер.
