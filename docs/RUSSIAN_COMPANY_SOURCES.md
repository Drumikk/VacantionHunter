## Маршрутизация

| Адаптер | Новых источников | Механизм |
|---|---:|---|
| Greenhouse | 9 | Публичный Board API |
| Ashby | 1 | Публичный Posting API |
| Lever | 12 | Публичный Postings API, включая EU endpoint |
| Workable | 3 | Публичный careers endpoint |
| Personio | 1 | Публичный XML feed |
| Универсальная карьерная страница | 150 | JSON-LD `JobPosting`, публичный Teamtailor feed, ссылки вакансий и ограниченная загрузка деталей |
| Уже существовавшие Greenhouse/Ashby/Personio | 5 | Дедупликация по компании |

Универсальный адаптер:

1. Загружает только allowlisted публичный URL из каталога и не использует cookies, логины или пользовательскую браузерную сессию.
2. Сначала читает schema.org `JobPosting` из JSON-LD.
3. Автоматически обнаруживает публичный Teamtailor widget key и читает public feed с пагинацией.
4. Затем извлекает ссылки, похожие на отдельные вакансии.
5. Загружает не более `MAX_GENERIC_DETAIL_PAGES` релевантных страниц деталей за поиск.
6. Кэширует индекс страницы на `CAREER_PAGE_CACHE_MS`.
7. Не переходит на LinkedIn и другие social hosts, не обходит CAPTCHA, Cloudflare, login wall или rate limits.

## Контроль полноты

Автоматические тесты проверяют:

- учтены ровно 202 строки и 200 компаний;
- ровно 180 компаний связаны хотя бы с одним допустимым connector ID;
- все 30 исходно пустых или LinkedIn-only строк либо получили подтверждённый supplemental source, либо перечислены в `research.unresolved`;
- LinkedIn URL не попадает в активные карьерные источники;
- ATS slug, generic URL и connector ID не дублируются;
- Teamtailor widget распознаётся, public feed нормализуется в общую модель вакансии;
- все допустимые строки связаны хотя бы с одним connector ID.

## Настройки

```dotenv
ENABLE_RUSSIAN_COMPANY_SOURCES=true
RUSSIAN_COMPANY_CATALOG_PATH=
MAX_GENERIC_DETAIL_PAGES=4
CAREER_PAGE_TIMEOUT_MS=8000
CAREER_PAGE_CACHE_MS=900000
CAREER_PAGE_MAX_BYTES=2000000
```

`ENABLE_RUSSIAN_COMPANY_SOURCES=false` отключает весь импорт без удаления каталога. `RUSSIAN_COMPANY_CATALOG_PATH` позволяет подменить каталог локальным JSON-файлом. Пользовательская авторизация и секретные API keys для этих источников не требуются.

## Ограничение

Каталог обеспечивает полное учётное покрытие PDF, но не превращает устаревший или закрытый URL в рабочий API. Для страниц, которые стабильно возвращают 403/404, требуют логин либо не содержат серверного HTML/публичного feed, корректный следующий шаг — официальный публичный ATS/API/feed или разрешённый партнёрский доступ. Имитировать пользовательский браузер, переносить cookies и обходить защиту приложение не будет.
